# Reference Assets Index

This folder contains verified visual assets from the repository and a snapshot of the current landing experience for Google Stitch.

## Assets List

1. **`current_landing_page.png`**
   - High-resolution visual capture of Weatherify's current unauthenticated landing page (`/signin`).
   - Demonstrates the current minimalist state: large headline, single description paragraph, "LET'S CREATE" button, and basic footer.
   - Use as the "Before" reference when redesigning the rich, feature-complete homepage in Stitch.

2. **`favicon.ico`**
   - Existing Weatherify brand icon and browser favicon.

3. **`Spotify_Icon_RGB_Black.png`**, **`Spotify_Icon_RGB_Green.png`**, **`Spotify_Icon_RGB_White.png`**
   - Official Spotify RGB icon marks in all three standard variants for light, dark, and brand-green usage.

4. **`Spotify_Logo_RGB_Black.png`**, **`Spotify_Logo_RGB_Green.png`**, **`Spotify_Logo_RGB_White.png`**
   - Official Spotify full wordmark logos for partnership badges and "Play on Spotify" CTAs.
